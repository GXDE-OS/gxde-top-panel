# DDE 图标风格

从 [deepin-icon-theme](https://github.com/linuxdeepin/deepin-icon-theme) 的 `bloom` 主题中
挑出的顶栏状态图标（GPL-3.0-or-later），供设置中「图标风格」选择：

| 目录 | 来源版本 | 用途 |
| --- | --- | --- |
| `dde23-dark` / `dde23-light` | 2023.04.03 | DDE V23 风格 |
| `dde25-dark` / `dde25-light` | 2024.07.31 | DDE V25 风格 |

- `*-dark`：深色面板使用，对应 bloom 的 `xxx.svg`（白色）
- `*-light`：浅色面板使用，对应 bloom 的 `xxx-dark.svg`（深色），改为同名文件
- 同名图标优先取 `status/20`（该目录深浅两版齐全），`status/16` 只补缺
